# GCC Mentor

GCC Mentor helps professionals prepare for Gulf jobs with one Career Profile,
job-specific resumes, cover letters and interview practice. Generated
materials use the candidate's real experience.

## Local development

Use Node.js 22 or newer. Install dependencies with `npm ci`, copy
`.env.example` to `.env.local`, and provide development Supabase settings.
Start the app with `npm run dev`. Run `npm run check` and `npm run build`
before opening a pull request.

See [AGENTS.md](AGENTS.md) for the code map and project rules. See the
[documentation index](docs/DOCUMENTATION_INDEX.md) for product specifications,
auth setup and deployment checks.
