# Mobile redesign evidence

All implemented-screen images in this folder use real built components with fictional local API replies. They contain no private audit screenshots or production user data. The approved reference is an image supplied through the design approval workflow; its values and saved-session state are illustrative.

- `dashboard-comparison.webp`: before / approved / implemented, normalized to 390px.
- `dashboard-{360,390,430}.webp`: implemented phone viewport captures.
- Other `*-390.webp`: full-page workflow evidence. The report deliberately uses long repeated fixture paragraphs to test wrapping and preserved content.
- `page-check-results.json`: route, viewport, heading/input counts and overflow outcomes for 114 built-page checks.

See the repository's `MOBILE_REDESIGN.md` for the token specification and preservation boundaries, and `design-qa.md` for checks, remaining limits and release scope. No numeric pixel-fidelity percentage is asserted.
