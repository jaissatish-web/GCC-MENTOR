# /docs/reports — Hermes's ticket reports

Each file here is Hermes's completion report for one ticket, named
`TASK-0NN.md`, in the exact format from `docs/HERMES.md` §6.

Written automatically as the last step of the autonomous loop described in
`docs/QUEUE.md`. The CTO reads these directly — the founder does not need to
copy report text into chat.

These are a running log, not documentation. Do not treat report content as
spec — `docs/` is the spec. Do not delete old reports; they are the audit
trail of what was actually built, by whom, and when.
