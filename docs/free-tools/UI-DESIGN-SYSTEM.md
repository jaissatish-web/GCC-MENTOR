# UI design system

Native white/light theme using existing typography.css and ui-system tokens. Scoped free-tools module; no global redesign. Compact hero, breadcrumbs, Free / No signup label, tool immediately visible. At360px use single column; wider screens may pair inputs/result. Labels above controls,44px touch targets, visible focus, errors linked via aria-describedby, error summary and live result status. Green only successful calculation, red actual error. Subtle borders, minimal shadows, colorful category icons; avoid nested cards.

Shared fields, Calculate/Generate and Reset, result breakdown/copy/print, assumptions/source disclosure, optional contextual CTA, substantial SSR educational section, helpful FAQ,3–4 related links and small final CTA. Results wrap safely and long text scrolls vertically. Search/filter empty state and keyboard navigation tested. Printing hides navigation and controls but includes useful result and assumptions. No intrusive popups.
