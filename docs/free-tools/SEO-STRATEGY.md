# SEO strategy

One canonical /tools/<slug> per tool in inventory. /tools catalog server renders links; client search/category/country filters progressively enhance it. Unique title `<Tool name> | Free Career Tool`, tool-specific description, canonical from SITE_URL, OG/Twitter image and en locale; no unsupported current-year claim. Server render purpose, who/how, worked example, mistakes, limitations, FAQ and related links. WebApplication and BreadcrumbList JSON-LD; escape embedded user-independent JSON. No fake ratings or FAQ rich-result promises.

Only completed indexable routes enter sitemap. No input URLs or indexed query variants. Robots must remain publicly permissive for /tools. Test resolved head rather than assuming inheritance. Existing GSC/Bing verification remains untouched; submit sitemap through webmaster account only if available/authorized. Test search intent with public competing pages; do not fabricate keyword volume. MenaJobs links gratuity/final-settlement/CV tools directly from home and provides optional account entry; use original contextual career CTAs. Performance targets: mobile90/accessibility90/best practices90/SEO95, LCP2.5s/CLS0.1/INP200ms; report environment and actual metrics, not guarantees.
