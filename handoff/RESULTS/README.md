# /handoff/RESULTS — Hermes's ticket reports

Each file here is Hermes's completion report for one ticket, named
`TASK-0NN.md`, in the exact format from `docs/HERMES.md` §6.

Written automatically as the last step of the relay described in
`handoff/STATUS.md`. The CTO reads these directly — the founder does not need
to copy report text into chat.

Named by ticket, not by timestamp, so the CTO can look one up by ticket
number. These are a running log, not documentation — do not delete old
reports; they are the audit trail of what was actually built, by whom, and
when.
